# Как помочь разработке

Спасибо за интерес к Shaking Hands. Проект открыт для идей, багрепортов и pull request.

## Перед тем как отправить Issue

Проверьте:

- используется Minecraft Forge `1.20.1 - 47.4.4`;
- установлены `player-animation-lib-forge-1.0.2-rc1+1.20` и `bendy-lib-forge-4.0.0`;
- у всех игроков на сервере одинаковые версии мода и зависимостей;
- баг повторяется после перезапуска клиента.

## Хороший багрепорт

Хороший багрепорт отвечает на вопросы:

- какая версия мода используется;
- одиночная игра, LAN или сервер;
- сколько игроков участвовало;
- какие кнопки нажимались;
- что должно было произойти;
- что произошло на самом деле;
- есть ли логи, скриншот или видео.

## Pull request

Перед отправкой изменений:

```bash
./gradlew build
```

На Windows:

```bat
gradlew.bat build
```

Пожалуйста, описывайте в PR не только что изменилось, но и зачем.

## Стиль проекта

- Не добавляйте скрытые сетевые запросы.
- Не добавляйте установщики и сторонние `.exe`.
- Не ломайте совместимость с Forge 1.20.1 без обсуждения.
- Для механик, завязанных на двух игроков, по возможности проверяйте клиент и сервер.
