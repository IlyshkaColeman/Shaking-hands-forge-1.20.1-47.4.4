# Поддержать Shaking Hands

Спасибо, что заглянули сюда. Даже небольшая поддержка помогает проекту жить: больше тестов, больше полировки, больше смешных и зрелищных механик для игры с друзьями.

## Как помочь бесплатно

- Поставьте ⭐ звезду репозиторию.
- Расскажите о моде друзьям или владельцу сервера.
- Откройте Issue, если нашли баг.
- Опишите идею новой механики.
- Приложите скриншот или видео странного поведения.
- Проверьте мод на сервере с несколькими игроками.
- Отправьте pull request с исправлением или улучшением.

## Платная поддержка

Автор не публикует номер карты, номер телефона и другие личные платёжные данные.

Поддержать проект можно через Boosty:

👉 **[boosty.to/coleman](https://boosty.to/coleman)**

Это безопасная публичная страница поддержки: игрок переходит по ссылке, выбирает удобный способ оплаты на стороне сервиса и не получает никаких личных платёжных данных автора.

## Что особенно полезно проекту

- Тесты на двух и более клиентах.
- Проверка анимаций от первого и третьего лица.
- Видео с багами таймингов.
- Предложения новых комбо.
- Идеи для звуков, HUD и эффектов.
- Проверка совместимости с популярными модпаками Forge 1.20.1.
