# Безопасность

## Откуда безопасно скачивать

Скачивайте официальные сборки только со страницы GitHub Releases этого репозитория:

https://github.com/IlyshkaColeman/Shaking-hands-forge-1.20.1-47.4.4/releases

Рекомендуемое имя файла:

```text
Shaking-hands-forge-1.20.1-47.4.4.jar
```

## Как проверить файл

У каждого публичного релиза должен быть SHA-256 хэш. Его можно сравнить с хэшем скачанного jar-файла.

Windows PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\Shaking-hands-forge-1.20.1-47.4.4.jar
```

Если хэш совпадает с указанным в релизе — файл не был изменён после сборки.

## Почему моду можно доверять

Проект открыт: любой игрок может посмотреть исходный код и собрать jar самостоятельно.

Мод:

- не содержит установщика;
- не просит логин или пароль от Minecraft;
- не требует доступ к браузеру, токенам или личным данным;
- не скачивает скрытые `.exe`-файлы во время игры;
- распространяется как обычный Forge `.jar` мод.

Если вы нашли подозрительный файл, фейковую страницу скачивания или проблему безопасности — создайте Issue в GitHub.
