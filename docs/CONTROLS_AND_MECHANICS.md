# Dap ur Homies (Forge 1.20.1) — Полный план управления и механик

Мод кооперативный: почти всё работает **в паре/группе игроков** (нужно 2+ клиента).
Большинство действий требуют **пустой основной руки**. Ниже — что на какую кнопку и как работает.

Все механики отключаемы через конфиг (`CoopMovesConfig`, флаги `enableX`), плюс есть
`noGriefMode` (отключает разрушение блоков взрывами).

---

## Клавиши по умолчанию

| Клавиша | Действие |
|--------|----------|
| **R** | Grab: поднять «руку захвата» (ready) / бросить того, кого держишь / отменить ready. Также «ловля» падающего (FallCatch). |
| **ПКМ по игроку** | Схватить игрока, у которого поднята рука захвата. Также подтверждение facing-dap при полном заряде. |
| **T** | Держать (когда кого-то держишь) — заряд броска (YEET), отпустить = бросок. Пусто/свободен: тап = пинок, удержание в спринте = заряд дроп-кика. |
| **V** | Держишь игрока — переключить «живой щит». Пусто — хлопок (Clap). |
| **H** | High Five: поднять руку. H+H в окне = комбо. ПКМ+H = sike (обманка). |
| **G** | Sync Dap: оба держат G, затем отпускают кнопку на горизонтальной шкале с бегущим ползунком. Оба должны попасть в одну цветную зону. Без найденного партнёра отпускание продолжает обычный дап. Также G отвечает на QTE/Fusion и запускает Meteor. |
| **Shift + G** | Классический заряд Dap. Этот режим нужен для тиров, Triple Dap, Fire, Fusion, Meteor и Heaven. |
| **J** | Fire-combo (в окне fire-dap). |
| **F** | Объятия (после хай-файва, удерживать) / Huddle (группой). |
| **Sneak (Shift)** | В воздухе будучи брошенным — spin (вертолёт); ещё раз — ground pound; в обычном прыжке — ground pound; когда тебя держат — вырваться. |
| **Space** | Будучи брошенным с элитрой — буст. |
| **WASD** | Воздушный контроль в полёте после броска. |
| **Shift + ПКМ по игроку** | Push (толчок): зарядка. |
| **/sit** | Команда — сесть. |

> Клавиши F (объятия/huddle) совпадают с ванильным «поменять руки» — это как в оригинале.

## Grab / Throw / Shield  (`enableGrab`, `enableThrow`/`enableYeet`, `enableShieldMode`)

- **R** с пустыми руками → поза «GRAB_READY» (рука поднята).
- Второй игрок жмёт **ПКМ по тебе** (пока у тебя ready) → он тебя держит (ты на его руках, поза GRABBED).
- Держащий: **R** ещё раз → бросить (drop).
- Держащий: **T** (удерживать) → заряд броска, отпустить → **YEET** (сила по заряду). Показывается дуга траектории.
- Держащий: **V** → «живой щит» (щит из тела удерживаемого; блокирует урон).
- Кого держат: **Shift** → вырваться (escape).
- В полёте после броска: **WASD** — воздушный контроль; **Space** с элитрой — буст.

## Spin / Ground Pound  (`enableSpin`, `enableGroundPound`)

- Будучи **брошенным и в воздухе** (поза GRABBED, не пассажир): **Sneak** → **Spin** (вертолёт, раскрутка).
  - Пока крутишься: пролетающих над наземными игроками «подхватываешь» пассажиром → взлёт вверх, затем **Sneak** → **МЕГА ground pound**.
  - Пока крутишься без пассажира: **Sneak** → обычный ground pound.
- Просто в воздухе (не брошен): **Sneak** → ground pound (пикирование вниз + AOE-удар с взрывом и откидыванием; высота падения усиливает урон; «мега» вариант мощнее).

## High Five  (`enableHighFive`, `enableHighFiveCombo`)

- **H** с пустыми руками → поднять руку (держится 2.5с, иначе «left hanging»).
- Оба игрока с поднятой рукой в радиусе ≤1.6 → хлопок; тир 0–3 по максимальной недавней скорости (беги/прыгай перед хлопком для тира повыше). Тир 3 = шоквейв.
- **H+H**: сразу после хай-файва (~1с окно) оба жмут **H** ещё раз → **Combo**: заморозка + второй perfect-удар.
- **Sike** (обманка): зажать **ПКМ** и нажать **H** → фейковый хай-файв; жертва оглушается и замедляется. Если оба сайкнули → **Mutual Sike** (обоих отбрасывает + урон).

## Hug / Huddle  (`enableHighFiveHug`, `enableHug`)

- **Hug**: после успешного хай-файва открывается окно; сначала — QTE-объятие (нажать **G** в ~1с окно → хореография с внутренним QTE). Если QTE-объятие не начато, через 2с открывается **hold-to-hug**: оба **держат F** рядом → объятие (сближение, сердечки, реген).
- **Huddle**: 2+ игрока **держат F** рядом друг с другом (стоя, вне окна хай-файва) → сбор в круг вокруг центра; можно присоединяться третьим. **Отпустить F** → 3 QTE-шага (**G**/**H** по подсказке) — при полном успехе баффы (Регенерация, Скорость, Сила, Сопротивление) + опыт; при провале — откидывание.

## MarioJump  (`enableMarioJump`)

- Прыгнуть на **голову** другого игрока → отскок вверх (как на мобе).

## Clap  (`enableClap`)

- **V** с пустыми руками (не держишь никого) → хлопок. Спам повышает тир (slow/spam/strong); ближние животные пугаются.

## Push  (`enablePush`)

- **Shift + ПКМ по игроку** → зарядка толчка; цель запускается вверх/назад. Есть иммунитет от повторного пуша.

## Kick / Drop-Kick  (`enableKick`, `enableDropKick`)

- **T** с пустыми руками (не держишь никого, поза NONE):
  - тап → пинок (небольшой толчок);
  - удержание **в спринте** → заряд дроп-кика, отпустить → мощный дроп-кик (вспышка на попадании: белая — пинок, оранжевая — дроп-кик).

## FallCatch  (`enableCatch`)

- Подними руку (**R**) рядом с падающим игроком → «поймать» его: отменяется урон от падения.

## Slap  (`enableSlap`)

- Полный заряд **G** и отпустить **без партнёра для дапа**, целясь в голову другого игрока:
  - сзади → back-slap («I like ya cut G»), камера жертвы дёргается;
  - спереди → front-slap.

## Mahito  (`enableMahito`)

- Проклятие через дап: если дапнуть игрока под эффектом Mahito → «тролл-смерть» (заморозка). Зелье Mahito есть в креативной вкладке Food & Drink.

## Sit

- Команда **/sit** — сесть на месте.

## Dap-семейство (ядро)  (`enableDap`, + под-флаги)

Базовый цикл: **G** (пусто) — заряд. Двигайся с полным зарядом — копится **огонь**.
Отпусти **G** рядом с партнёром (который заряжает или держит руку) и **смотрите друг на друга** — дап.

**Sync Dap по G**:
- появляется горизонтальная шкала с зонами: серая, жёлтая, зелёная, красная, зелёная, жёлтая, серая;
- ползунок постоянно бегает слева направо и обратно;
- оба игрока отпускают **G** и должны попасть в одну цветную зону;
- **серая зона** или разные зоны → провал, звук промаха и `The loser failed`;
- **жёлтая зона** → обычный хлопок;
- **зелёная зона** → сильный хлопок;
- **красная середина** → самый мощный хлопок, шейдерные impact-эффекты и запуск G-комбо.

**Классический Shift+G заряд** (по среднему заряду + суммарной скорости + огню):
- 0 — Weak, 1 — Decent, 2 — Good, 3 — Great/Perfect, 4 — Legendary, 5 — Fire Dap.
- **Triple Dap** — три игрока разом.
- **Facing Dap** — **ПКМ по игроку** при полном заряде у обоих (взаимное подтверждение) → dap-loop.

**Огонь / Fire Dap / Heaven** (`enableFireDap`, `enableHeavenDap`):
- Держи полный заряд и двигайся ~2с → строится огонь; полный огонь ~5с → **HEAVEN READY** (в HUD).
- Оба с огнём ≥90% → **Fire Dap** (тир 5): огненный удар + окно **fusion** (G) и **fire-combo** (J).
  - **J** в окне → **Divine Flame Combo** (огненное торнадо, aura-beam, огненные стены).
  - **G** в окне → **Dap Fusion** (слияние; далее QTE).
- Оба **HEAVEN READY** + скорость/perfect → **Heaven Dap**: телепорт на Y=500, полёт, возврат с «Perfect Friendship» (или гибель, если «сила слишком велика»).

**Dap-комбо / Perfect-combo / Fusion / Meteor** (`enableDapCombo`):
- После great/perfect дапа может открыться **QTE-цепочка** — жми **G**/**H** по подсказкам (окно рисуется в HUD).
- После **Fusion** даётся способность **Meteor**: в HUD «☄ METEOR READY — press **G** to fire»; **G** запускает метеор в точку взгляда.

**FallDap** (`enableFallDap`): дап во время падения. **DapHold** (`enableDapHold`): удержание дапа.

## HUD и визуальные эффекты

- **Бар заряда/огня** по центру: оранжевый→зелёный (заряд), красный overcharge (огонь), тряска+«трещины» при HEAVEN READY.
- **Мини-бары партнёров** рядом (в радиусе 20).
- **Бар whiff-кулдауна** (промах), промпт **«🔥 PRESS J!»** в fire-combo окне.
- **Impact-кадры удара** (perfect/facing dap) — полноэкранные текстуры.
- **CoopImpact-силуэт** — игроки мелькают белым/чёрным силуэтом на импакте (шейдер).
- **Heaven White Overlay** — белая вспышка на heaven-дапе.
- **Дуга броска** (при заряде YEET), **Spin/GroundPound/Meteor HUD**, **Kick hit-flash**.
- **Косметика верхних тиров**: огненное торнадо, кольца Сатурна, aura-beam, каскад heaven-частиц, sonic-кольца, star-burst.

## Статус проверки (аудит порта)

Проверено и корректно:
- Все механики подключены (server tick + client register + сообщения в едином канале).
- Кейбинды не теряются; QTE отвечает на G/H.
- Анимационные состояния (ординалы) сервера совпадают с клиентским enum → правильные позы.
- Ассеты на месте: 153 анимации KosmX, звуки+sounds.json, lang, GUI-текстуры impact, core-шейдеры.
- Баг «R не реагирует после смерти» — исправлен (очистка состояния на смерть/респаун/выход).

Проверять в игре (компиляция зелёная, но рантайм зависит от среды):
- **CoopImpact-силуэт** (загрузка core-шейдеров + миксин рендера) — есть безопасный фолбэк на обычный рендер, если шейдер не поднимется.
- **Первое лицо** (KosmX FP) — попозная видимость рук.

Известные мелочи (не баги):
- У **Ground Pound** в исходном репозитории нет файлов анимации dive/land — работает геймплей без отдельной позы.
- Клавиша **F** делит функции с ванильным «поменять руки» (как в оригинале).
- Мьют громкости во время heaven-дапа не переносился (визуал есть).
